# 📱 Mobile Phone Recommendation System

Content-based filtering system that recommends mobile phones based on user preferences
like budget, camera quality, battery, RAM, and brand.

**Dataset:** [Kaggle — Cellphones Recommendations (meirnizri)](https://www.kaggle.com/datasets/meirnizri/cellphones-recommendations)

## Setup & Run

### 1. Install dependencies
```bash
pip install -r requirements.txt
```

### 2. Add your Kaggle dataset
Download from Kaggle and place the CSV at:
```
data/cellphones_data.csv
```
The file should have these columns:
`cellphone_id, brand, model, operating system, internal memory, RAM, performance,
main camera, selfie camera, battery size, screen size, weight, price, release date`

### 3. Train the model (run once)
```bash
python train.py
```
This preprocesses the data, normalizes features, computes the similarity matrix,
and saves all artifacts to `models/` using **joblib**.

### 4. Start the Flask app
```bash
python app.py
```
Open **http://127.0.0.1:5000** in your browser.

### 5. (Optional) Run the Jupyter notebook
```bash
cd notebooks
jupyter notebook mobile_recommender.ipynb
```

## How the Recommendation Works

1. **Preprocessing** — Min-Max normalization on all numeric features.
2. **User preference vector** — Slider weights form a vector `[storage, RAM, performance, camera, selfie, battery, screen]`.
3. **Candidate filtering** — Phones filtered by budget range and OS preference.
4. **Cosine similarity** — Similarity computed between user vector and each candidate's feature vector.
5. **Brand bonus** — +0.05 added if phone brand matches preferred brand.
6. **Ranking** — Top-N phones by similarity score returned.

## API Endpoints

| Method | Route | Description |
|--------|-------|-------------|
| GET | `/` | Main recommendation UI |
| POST | `/recommend` | Get recommendations (JSON) |
| GET | `/api/stats` | Dataset statistics |
| GET | `/api/phones` | Full phone list |

### POST /recommend — Request body
```json
{
  "budget_min": 200,
  "budget_max": 800,
  "os_pref": "Android",
  "brand_pref": "Samsung",
  "camera_w": 0.8,
  "selfie_w": 0.4,
  "battery_w": 0.9,
  "ram_w": 0.6,
  "performance_w": 0.5,
  "storage_w": 0.4,
  "top_n": 5
}
```
